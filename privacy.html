개인정보처리방침

적용 대상: google-tasks-mcp-readonly (개인용 구글 태스크 읽기 전용 도구)
시행일: 2026년 11월 7일

1. 이 앱이 하는 일

이 앱은 앱을 직접 실행하는 사용자 본인의 구글 계정에서 Google Tasks의 태스크 목록과 태스크를 읽습니다. 태스크를 만들거나 수정하거나 삭제하지 않습니다.

2. 요청하는 구글 권한

https://www.googleapis.com/auth/tasks.readonly (구글 태스크 보기) 한 가지입니다.

3. 데이터의 처리

  • 앱은 사용자의 컴퓨터에서만 실행됩니다. 개발자가 운영하는 서버는 없습니다.
  • 개발자는 사용자의 태스크나 계정 정보를 수집, 저장, 판매, 공유하지 않습니다.
  • 로그인 토큰은 사용자 컴퓨터의 로컬 파일에만 저장됩니다.
  • 사용자가 연결해서 쓰는 AI 도구(예: Claude)가 요청할 때 태스크 내용이 해당 도구에 전달됩니다. 이는 사용자 본인의 요청에 따른 것이며, 해당 도구의 개인정보 정책이 적용됩니다.
  • 구글 API로 받은 데이터는 사용자에게 기능을 제공하는 목적으로만 사용하며, Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 준수합니다.

4. 접근 권한 삭제

언제든지 구글 계정의 서드파티 앱 및 서비스에서 이 앱의 접근 권한을 삭제할 수 있고, 컴퓨터의 토큰 파일을 삭제하면 저장된 로그인 정보가 사라집니다.

Privacy Policy (summary)

This personal tool reads only the Google Tasks of the account of the person who runs it, using the tasks.readonly scope. It runs on the user's own computer; the developer operates no server and does not collect, store, sell or share user data. Sign-in tokens are stored only in a local file on the user's computer. Task content is passed to the AI assistant the user chooses to connect, at the user's request. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
